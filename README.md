# SPROUT

## Reason for making

I recently started building a project which required much optimization as my user count grew. I could see the improvements I made because I already had the DAU (daily active users) to provide a baseline usage to compare against. For many people who want to learn how to optimize their projects, they can apply techniques but often they don't have the usercount to test against to see the impacts of their change. I thought a fun project would be to create an open-sourced, self-hostable, optimization testing tool.

## Ways of using

1. Using the UI & building user profiles through input containers as a wrapper around the basic profile code
2. Creating your own user profiles in code
